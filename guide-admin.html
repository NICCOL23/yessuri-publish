집수리 준비 안내 편집

초안은 관리자만 볼 수 있습니다. 게시 후 메인 안내 문구에 반영되며 아이콘·사진·번호·배치는 유지됩니다.

문구를 불러오는 중입니다.

준비 안내는 이렇게 수정하세요

메인의 ‘집수리, 이렇게 준비하세요’ 문구를 바꾸는 곳입니다. 사진·아이콘·배치는 유지됩니다.

  1. 내용 수정바꿀 항목만 수정하세요.
  2. 초안 저장관리자만 볼 수 있게 저장합니다. 홈페이지는 아직 바뀌지 않습니다.
  3. 미리보기·변경 비교저장한 초안을 PC·휴대폰으로 확인하고 현재 공개 내용과 비교하세요.
  4. 홈페이지에 게시확인 표시를 한 뒤 게시 버튼을 눌러야 방문자에게 반영됩니다.

수정을 시작하지 않고 둘러보기만 해도 됩니다. 잘못 게시했다면 아래 ‘게시 기록과 복원’에서 이전 내용을 확인하세요.
