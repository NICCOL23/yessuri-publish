수정 내용은 관리자만 확인하며 게시 후 메인 분야 박스에 반영됩니다. 메인 숨김은 카드에만 적용됩니다. ‘분야 사용’을 끄면 새 선택 목록에서 제외되며 기존 자료의 연결은 유지됩니다.

메인 분야 박스의 이름·설명·아이콘·순서·표시 여부를 바꾸는 곳입니다. 검색·등록 신청의 분야 연결은 유지됩니다.

  1. 내용 수정바꿀 항목만 수정하세요.
  2. 수정 내용 저장관리자만 볼 수 있게 저장합니다. 홈페이지는 아직 바뀌지 않습니다.
  3. 미리보기·변경 비교저장한 수정 내용을 PC·휴대폰으로 확인하고 현재 공개 내용과 비교하세요.
  4. 홈페이지에 게시확인 표시를 한 뒤 게시 버튼을 눌러야 방문자에게 반영됩니다.

수정을 시작하지 않고 둘러보기만 해도 됩니다. 잘못 게시했다면 아래 ‘게시 기록과 복원’에서 이전 내용을 확인하세요.
