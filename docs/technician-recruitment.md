# 기술자 모집·등록

- `technician-board.html`: 기존 게시판 주소 유지. 상단에 연도·모집 상태와 신청/조회/모집 안내 링크를 표시합니다.
- `technician.js`: 게시판 상단 템플릿만 변경했습니다. API 호출·인증·사진 첨부·신청 처리 코드는 그대로입니다.
- `technician-recruit.css`: 게시판 모집 강조와 별도 안내 페이지의 스타일을 관리합니다. 기존 글꼴 변수를 사용하며 연도는 실제 텍스트입니다.
- `technician-recruit.html`: 모집 대상·19개 분야·신청 과정·준비 자료·검토 중인 홍보 계획을 관리하는 단일 안내 페이지입니다.
- 공통 상단 메뉴의 표시 문구만 ‘기술자 모집·등록’으로 바꾸고 `register.html` 연결은 유지했습니다. 푸터는 변경하지 않았습니다.
- 사용자의 최종 지시에 따라 `index.html`에서 `technician-promo.js/css` 로드를 제거했습니다. 팝업 원본 파일은 남아 있지만 메인에서 실행하지 않습니다.

## 문구 수정

오픈 연도와 짧은 모집 상태는 `technician.js`의 `board()` 상단 템플릿에서 수정합니다. 모집 상세 내용은 `technician-recruit.html`에서 관리합니다. ‘무료’·우선 노출·고객 연결 보장 문구를 임의로 추가하지 않습니다.

## 2026-10-22 검증

- 1920/1440/1280/768/390/320px: 게시판과 모집 안내 화면 확인, 가로 넘침 없음.
- 200% 글자 확대, 사용자 글자 간격 변경: 가로 넘침 없음. 모바일 메뉴와 Esc 닫기 확인.
- 상단 링크 3개, 모집 안내의 등록/조회/게시판 복귀, 키보드 초점 확인.
- 신청서 화면의 사진 선택과 동의 컨트롤 존재 확인. 운영 데이터 전송을 막은 상태로 검증하여 실제 제출/비밀번호 인증/수정/삭제는 실행하지 않았습니다.
- 메인의 19개 분야 카드 유지, 팝업 미실행 확인.
- 전체 접근성 인증이 아닌 변경 범위 중심의 검증입니다.
