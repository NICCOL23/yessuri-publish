# 수리·관리 팁 관리 기록

2026-10-16 구현. 작업·비용·상담 안내와 구분하여 관찰·평소 관리·전문 점검 시점을 안내한다.

## 수정 범위와 기준 데이터

- 기존 파일 변경: `guide.html`의 `#repair-tips` 내용과 팁 전용 CSS/JS 로드 2개만 변경.
- 전용 파일: `repair-tips.js`, `repair-tips.css`, `data/repair-tips.json`.
- 팁의 편집 기준은 JSON 한 곳. HTML에 8개 본문을 복사하지 않는다.
- 기존 `data/work-catalog.json`과 93개 이미지, 작업 컨트롤러·패널, 모든 다른 페이지는 수정하지 않았다.
- 기존 이미지 5장은 기존 이미지 ID를 참조한다. 경로·제작 메타데이터를 복제하지 않는다.
- 신규 이미지 3장은 `assets/images/repair-tips/v1/`에 저장. 이 폴더의 WebP는 최적화한 표시용이며 원본 PNG는 아래 검토 폴더에 보존한다.
- 생성 도구: built-in imagegen. 실제 프롬프트는 이 문서 옆 `prompts/`에 보존. 신규 제작·시각 검토·파일 해시는 팁 JSON의 `newImages`에 기록.
- 그림은 이해를 돕는 참고 표현이며 특정 제품의 구조를 인증하거나 현장 원인을 진단하는 자료가 아니다.

## 중복 제거와 기존 문장 보존

기존 팁의 내용은 의미에 따라 다음에 보존된다. 다른 구역은 재작성하지 않았다.

| 기존 의미 | 보존 위치 |
| --- | --- |
| 전체·문제 부위 사진 구분, 깨진 유리·전기 설비 만지거나 분해하지 않기 | 팁 하단 작은 ‘상담 전 참고사항’; 기존 작업 상담의 안전 촬영 안내도 유지 |
| 제품명만으로 호환성 판단하지 않고 기존 규격·설치 조건 확인 | ‘상담 전 참고사항’; 기존 FAQ ‘직접 구매한 제품’과 작업별 규격도 유지 |
| 추가 작업은 내용·비용·일정에 동의한 뒤 진행 | 기존 FAQ ‘추가 작업이 필요하면’ 및 기존 상담·이용 절차 ‘비용·일정 협의’에 보존. 새 팁 상세에서는 반복하지 않음 |
| 견적·변경된 작업 내역 보관 | ‘상담 전 참고사항’의 고유한 한 문장으로 보존 |
| 작업 후 정상 작동·마감·사후 점검·재방문 조건 확인 (`check-title`) | 기존 93개 작업 상세의 ‘작업 후 함께 확인하세요’와 FAQ 사후 점검·보증·재방문 안내에 이미 보존되어 팁의 공통 말미 배너는 제거 |

팁에는 비용표·지역·제품 선택·상담 문구를 복제하지 않는다. 관련 작업 1개를 기본으로 하고 곰팡이만 결로 원인 점검과 청소의 2개 연결을 제공한다. 공통 안전 배너는 추가하지 않고 전기 카드의 배지와 해당 상세의 우선 조치만 둔다.

## 패널·주소·상태

- PC: 왼쪽 1040px 이내 넓은 native dialog, 왼쪽→오른쪽 애니메이션, 어두운 배경. 900px 이하 전체 화면. 본문만 내부 스크롤한다.
- 목록은 PC 2열, 700px 이하 1열. 320px에서도 잘림·가로 넘침 없이 제목이 자연스럽게 줄바꿈된다.
- `guide.html?tip=mold-moisture#repair-tips` 등으로 직접 접근할 수 있다. 팁을 열 때 기존 검색 매개변수와 hash는 그대로 두고 `tip`만 추가한다.
- 팁 방문 기록은 `history.state.repairTip`, 기존 작업 기록은 그대로 `wgFlow`. 팁 매개변수 변경 시 기존 스냅샷의 route 키만 해당 주소로 맞춘다. 서버 전송·localStorage·장기 저장 없음.
- 같은 주소에 작업과 팁이 함께 있으면 작업 상태는 유지하고 팁 하나만 표시한다. 팁 닫기 후 원래 작업 상태로 돌아간다.
- 관련 작업은 기존 작업 컨트롤러가 처리하는 URL과 popstate 경로로 전환한다. 기존 파일은 수정하지 않으며 지역·제품 선택을 유지한다.
- 닫기·목록 복귀·Escape·배경 클릭, Tab 순환과 카드 초점·목록 위치 복원, 뒤로·앞으로 가기의 상세 읽던 위치 복원을 지원한다.
- 동작 줄이기에서는 이동 애니메이션 없음. 창이 겹쳐 열리지 않도록 팁 전용 코드에서 조정한다.
