# 공통 푸터 관리

모든 실제 화면의 푸터는 `<yessuri-site-footer>` 컴포넌트 인스턴스입니다. 다른 화면으로 이동만 하는 `register.html`, `register-form.html`은 목적지 화면의 공통 푸터를 사용합니다.

- 문구·로고·메뉴·저작권: `site-footer.js`의 공통 템플릿에서 수정합니다.
- 여백·정렬·모바일 배치: `site-footer.css`에서 수정합니다.
- 페이지별 HTML에 푸터 내용을 따로 복사하지 않습니다.
- 컴포넌트는 Shadow DOM으로 페이지별 스타일과 분리됩니다. 로고와 링크 주소는 스크립트 파일 위치를 기준으로 계산합니다.
- CSS 변경 시 `site-footer.js` 안의 CSS 버전을 올립니다. JS 변경 시 각 페이지의 `site-footer.js?v=` 버전을 함께 올려 캐시를 갱신합니다.
- 푸터 수정은 정적 사이트 배포 후 전체 페이지에 반영됩니다. 게시판·등록 데이터와 관리자 인증은 수정하지 않습니다.
