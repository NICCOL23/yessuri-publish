# 열쇠·도어락 분야 추가 하네스

승인 범위: 19→20분야, 문·창호 다음/에어컨 앞. 새식별자 locksmith, 저장명 열쇠·도어락. 예시업체3곳 추가 승인됨. 기존업체/사진/후기/등록신청/작업이력은 보존한다. 상품 시연몰·Mercur 제외. 유료 가입·결제 금지.
