## 실행 제한

정적 검증 실행은 Node의 git 자식 프로세스 생성이 sandbox EPERM으로 거부되어 assertion 시작 전 중단되었다. 상위 통합 담당에게 권한 있는 실행을 요청했다. 브라우저 실행도 통합 담당이 수행하도록 전달했으며 여기서는 브라우저 실행 권한을 요청하지 않았다. 결과가 오기 전 통과로 보고하지 않는다.

## 코드 검토로 확인한 주의 사항

관리자 technician-public-profile.js 전문 분야는 아직 쉼표 구분 자유입력란이다. 새 한국어 분야 입력 자체는 서버가 허용하지만 등록 화면과 동일한 공통 선택 UI는 현재 연결되어 있지 않았다. 동일 선택 UI 요구 충족 여부를 통합 담당이 결정/보완해야 한다.

기존 회귀 테스트의 고정 수 기대치는 새 샘플3개를 반영해야 한다. test-find-real-and-examples는 61개/6페이지(마지막1개), 25개 실제 fixture일 때85개/8페이지(마지막1개)가 된다. 단순58→61 치환만으로는 전체 페이지 검증이 되지 않는다. test-home-pagination-layout, test-expert-restore, test-profile-journal도 고정57/58 값을 확인해야 한다. 이 작업자는 범위 충돌 방지를 위해 기존 테스트를 직접 수정하지 않았다.
