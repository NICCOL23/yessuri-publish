# 공통 이전 페이지 버튼

`page-back.js`, `page-back.css`가 공통 복귀 버튼을 제공합니다. 메인에는 버튼을 표시하지 않고 이동 기록만 준비합니다. 각 HTML에는 두 파일 참조만 추가했으며, 본문이나 기존 검색 코드는 수정하지 않습니다.

같은 탭에서 사이트 안의 페이지를 이동한 기록이 확인되면 브라우저의 이전 이동을 사용합니다. 기존 검색 조건과 스크롤 복원 동작을 유지하며, 바로 접속했거나 이동 기록을 확인할 수 없으면 관련 목록으로 연결합니다. 기본 목적지는 JS의 `defaults`에서 관리합니다.

기존의 명확한 이전·목록 복귀 링크만 공통 버튼이 있을 때 `data-page-back-duplicate`로 숨깁니다. 원본 링크와 이동 주소는 보존하며, 자바스크립트가 동작하지 않으면 원래 링크가 표시됩니다. 작업 선택·닫기·페이지 번호의 이전·폼 제출 버튼은 대상이 아닙니다.

검증: 메인 표시 제외, 페이지별 1개 표시, 직접 접속의 관련 목록 연결, 검색→프로필→검색의 분야 조건 복원, 중복 숨김, 키보드 및 모바일 표시.
